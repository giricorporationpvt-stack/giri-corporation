## 🎨 Design Philosophy & Architecture

- **Microsoft Fluent 2 Enterprise Aesthetics**: Clean acrylic glass surfaces, crisp 6px CTA buttons, spotlight banners, quick-access launcher ribbons, and high-contrast typography.
- **Zero Build-Step Stack**: Pure ES2022 JavaScript modules, semantic HTML5, and vanilla CSS3 variables. No bulky bundle overhead, sub-15ms edge first contentful paint (FCP).
- **Service Worker (PWA)**: Implements Stale-While-Revalidate and Network-First caching for immediate offline resiliency.
- **Full Indian Language Accessibility**: Sovereign client-side localization supporting English, Hindi (हिंदी), Bengali (বাংলা), Telugu (తెలుగు), Marathi (मराठी), and Tamil (தமிழ்).
- **Zero-Tracker Guarantee**: Strictly no third-party tracking scripts, cookies, or telemetry.

## 🌐 Deployment

This site is optimized for global edge CDN hosting (Cloudflare Pages, Vercel, or GitHub Pages):

1. **Static Files**: Zero build command required. Publish directory: `./` (root).
2. **Custom Domain**: Point your DNS CNAME to the edge distribution.
3. **PWA**: Automatically registers `/sw.js` upon HTTPS load.
